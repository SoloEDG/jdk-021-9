# 午市厨房

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

类型检查及生产构建：

```sh
npm run typecheck
npm run build
```

运行测试：

```sh
npm test
```

Docker 启动：

```sh
docker compose up --build
```

打开 http://localhost:18221 。

## 营业回放与分叉演练

打烊后，本场营业会自动沉淀为一条**可交互回放**（页面下方「营业回放」区）：

- **拖到任意时刻**：时间轴可拖动 / 点击事件跳转 / 自动播放，随时查看当时的
  库存、设备、订单与账本；接单、备料、下锅、起锅、装盘、上菜、自动到客、
  离店等事件全部在册，同一时刻发生的多件事按序号保持稳定顺序。
- **分叉演练**：在任意时刻点「分叉演练」，复制当时局面开一条演练线
  （例如提前两秒起锅），只沿新决定推进；原回放完整保留，原时间线里
  分叉点之后的交付不会被混用。完成后自动生成**逐笔收入差异**表与
  **首个分歧原因**说明。
- **长局分段恢复**：拖动时从最近检查点分段恢复，切换回放或连续拖动时，
  迟到的恢复结果不会覆盖新选择。
- **安全边界**：回放与演练在沙盒状态中进行，不会触发真实采购，
  也不会改写历史最佳。
- **导出 / 导入**：回放可导出为 JSON 文件；导入时逐条校验（格式、版本、
  校验和、重模拟一致性），能还原相同场面，不兼容的记录会被识别并说明原因。
